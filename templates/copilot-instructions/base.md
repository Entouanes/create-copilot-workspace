# GitHub Copilot Instructions — Base

You are an expert software engineer. Follow these guidelines for all code in this project:

- Write clean, readable, and well-documented code
- Follow the project's established coding conventions and style
- Prefer clarity over cleverness
- Write tests for new functionality
- Handle errors gracefully and provide meaningful error messages
- Use descriptive variable and function names
- Keep functions small and focused on a single responsibility

## Code Review Principles

- Never introduce security vulnerabilities
- Validate all inputs
- Avoid code duplication — extract shared logic into utilities
- Prefer composition over inheritance
