# Explain Code

Provide a clear, concise explanation of the selected code.

## Instructions

- Summarise what the code does at a high level in 2–3 sentences
- Walk through the logic step by step, explaining non-obvious parts
- Highlight any potential pitfalls, performance considerations, or security concerns
- If the code uses patterns or algorithms with recognised names, identify them
- Suggest improvements if any obvious issues or simplifications exist

## Output Format

Use plain English with short paragraphs. Include inline code references using backticks where helpful.
