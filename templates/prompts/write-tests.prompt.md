# Write Tests

Generate comprehensive tests for the selected code.

## Instructions

- Identify the testing framework already used in the project (Jest, Vitest, pytest, etc.) and follow the same conventions
- Write both happy-path and edge-case tests
- Mock external dependencies (APIs, databases, file system) where appropriate
- Use descriptive test names that explain the expected behaviour
- Aim for high coverage of the public API surface

## Output Format

Return only the test file content, ready to save alongside the source file being tested.
